# Existing Windows daily-wallpaper apps: landscape and gap analysis for backreel

Research date: 2026-11-04. Anything older is dated inline.

Evidence labels used throughout:
- **[Direct]**: read directly during this research from a primary artefact (HTTP `Content-Length` of the real installer, GitHub release/repo API, Microsoft Store catalogue API, or static inspection of a package). Exact, but says nothing about runtime RAM/CPU.
- **[Reported]**: a figure a third party says they observed.
- **[Claim]**: a vendor or author's unmeasured statement.
- **[Snippet]**: taken from a search result summary; the full page was not read (usually because it returned HTTP 403). Treat as weaker.

No app was installed or run for this research, so **no RAM or CPU figure here was measured by this research**.

## How does the official Microsoft Bing Wallpaper app work, what is its footprint, and what complaints exist?

### Takeaway
It is a resident, auto-starting, full-trust .NET/WinUI app that ships browser-default-changing machinery inside the wallpaper package: 46 MB download, 85.7 MB unpacked, plus a Windows App Runtime dependency. In September and October 2026 it moved from "pushy" to openly ad-bearing, with a full-desktop film ad and desktop clicks that open Bing. No reliable RAM measurement exists.

### Cited Findings

**Current package (static inspection of 1.1.459, not executed)**
- The winget manifest lists `Microsoft.BingWallpaper` 1.1.459, type MSIX, x86, release date 2026-03-12, licence "Proprietary (Freeware)" [Direct] — [winget / installer URL](https://download.microsoft.com/download/3c0e11a1-2e57-4bc3-b877-1a04248078a4/W011/0x00005001/BingWallpaper_1.1.459.0_x86.msix)
- Download size is 45,998,624 bytes (46.0 MB), server `Last-Modified` 2026-07-24. Unpacked it is 85.7 MB across 338 entries, of which 63.5 MB is DLLs [Direct] — [package](https://download.microsoft.com/download/3c0e11a1-2e57-4bc3-b877-1a04248078a4/W011/0x00005001/BingWallpaper_1.1.459.0_x86.msix)
- Stack: self-contained .NET 9-series runtime (`coreclr.dll`, `System.Private.CoreLib.dll`, `mscordaccore_x86_x86_9.0.1826.31522.dll`), WinUI (generated by Template Studio, project type "MenuBar"), WinUIEx, CommunityToolkit, LiteDB, Polly, `WebView2Loader.dll`, `msquic.dll`. It also has a package dependency on `Microsoft.WindowsAppRuntime.1.7`, so true on-disk cost is above 85.7 MB [Direct] — [package](https://download.microsoft.com/download/3c0e11a1-2e57-4bc3-b877-1a04248078a4/W011/0x00005001/BingWallpaper_1.1.459.0_x86.msix)
- Manifest: `windows.startupTask` with `Enabled="true"`, toast activation, a File Explorer context-menu shell extension on `Directory\Background` (`BingWallpaperDesktopContextMenu.dll`, COM surrogate), a `microsoft-bingwallpaper:` protocol, and an execution alias. Capabilities: `internetClient`, `runFullTrust`, `packageManagement` (commented "needed for upgrade"), `unvirtualizedResources` (commented "needed for register unis. daemon") [Direct] — [package](https://download.microsoft.com/download/3c0e11a1-2e57-4bc3-b877-1a04248078a4/W011/0x00005001/BingWallpaper_1.1.459.0_x86.msix)
- Executables: `BingWallpaper.exe`, `UnInstDaemon.exe`, `Resources/NativeMessaging/NativeMessagingHost.exe`, `createdump.exe`. All PE files checked are x86 [Direct] — [package](https://download.microsoft.com/download/3c0e11a1-2e57-4bc3-b877-1a04248078a4/W011/0x00005001/BingWallpaper_1.1.459.0_x86.msix). This conflicts with an October 2025 community answer describing a 64-bit main process and 32-bit helper; that answer cites no documentation and may describe a different build or distribution — [Microsoft Q&A](https://learn.microsoft.com/en-us/answers/a/12285545)
- The package ships `BrowserDefMgr.dll` plus `Resources/BrowserDefaults/bing.zip` and `msn.zip`, which are complete browser extensions. Their manifests use `chrome_settings_overrides` to set the homepage (bing.com / msn.com/feed) and a Bing `search_provider` with `is_default: true`. The Bing extension's host permissions include `browserdefaults.microsoft.com`, `services.bingapis.com`, `chrome.google.com`, and `dc.services.visualstudio.com`. A native messaging host (`com.microsoft.bwnativemsghost`) is included [Direct] — [package](https://download.microsoft.com/download/3c0e11a1-2e57-4bc3-b877-1a04248078a4/W011/0x00005001/BingWallpaper_1.1.459.0_x86.msix)
- String scan: `Local State` and `Secure Preferences` occur in `BingWallpaper.dll` and `BrowserDefMgr.dll`; `DefaultSearch` occurs 38 times, `telemetry` 17, `ShowAI` 15, `BingVisualSearch` 15, `OpenBing` 10 in `BingWallpaper.dll`; `SetWindowsHookEx` occurs 3 times in `BingWallpaper.Widgets.dll`; `telemetry` occurs 3 times in `UnInstDaemon.exe`. Plain-text `Cookies`, `MUID`, and `DesktopClick` were **not** found in any non-framework binary [Direct] — [package](https://download.microsoft.com/download/3c0e11a1-2e57-4bc3-b877-1a04248078a4/W011/0x00005001/BingWallpaper_1.1.459.0_x86.msix). Strings prove neither presence nor absence of a behaviour; see Inferences.

**Marketing and terms**

Installing means accepting the Services Agreement and agreeing to in-app promotional notifications. The page does not mention search or browser changes. - Store listing `XPFP7F8RL7MB1W`: Free, 4.5 stars from 781 ratings (US), `LastUpdateDateUtc` 2024-10-16 [Direct] — [Store catalogue API](https://storeedgefd.dsx.mp.microsoft.com/v9.0/products/XPFP7F8RL7MB1W?market=US&locale=en-us&deviceFamily=Windows.Desktop). That date predates the 2026 package, so it does not appear to track app versions.

**2024: "malware-like" allegations**
- Rafael Rivera (decompiled with ILSpy, observed in Windows Sandbox) said the app alters Chrome extension preferences, decrypts and reads "all major browser cookies for user tracking purposes", uses configurable prompts and encrypted config, detects or intercepts browser launches to promote extensions and open URLs, can be remotely reconfigured, and installs Bing Visual Search without asking. He said he had only "scratched the surface" — [The Register, 2024-11-26](https://www.theregister.com/2024/11/26/bing_wallpaper_app/)
- Rivera said the app locates Chrome, Edge, and Firefox cookie stores, queries cookies such as MUID, and decrypts them without user intervention — [The Register, 2024-11-26](https://www.theregister.com/2024/11/26/bing_wallpaper_app/)
- Microsoft replied that the app "does not peruse and decrypt *all* user Edge and Chrome cookies" and that it does a Bing cookie check to avoid re-offering the Bing app. It did not mention Firefox. Rivera called this "splitting hairs" — [The Register, 2024-11-26](https://www.theregister.com/2024/11/26/bing_wallpaper_app/)
- ESET classifies the app as a potentially unwanted program — [The Register, 2024-11-26](https://www.theregister.com/2024/11/26/bing_wallpaper_app/)

**October 2025: click hijack and settings**
- A "Desktop click opens Bing" toggle was on by default. Also on by default: top-right visual search and a recommendations/news/announcements toggle. Other items: a Hotspot Widget, notifications for News and Microsoft Recommendations, "Daily wallpaper refresh", and "Show AI images" — [Windows Latest, 2025-10-26](https://www.windowslatest.com/2025/10/26/windows-11s-bing-wallpaper-app-opens-bing-com-if-you-click-anywhere-on-the-desktop/)
- On install, a pop-up asks to set Bing as homepage and default search for Edge, Firefox, and Chrome, with a prominent button applying it to all three — [Windows Latest, 2025-10-26](https://www.windowslatest.com/2025/10/26/windows-11s-bing-wallpaper-app-opens-bing-com-if-you-click-anywhere-on-the-desktop/)

**September 2026: full-desktop ad**
- On Monday 2026-09-07, users found their wallpaper replaced by a Harry Potter/Fantastic Beasts "11-film collection" ad. Complaints appeared on Reddit, Microsoft Learn Q&A, and as 1-star Store reviews, some noting the settings now say AI generates some wallpapers. The Register got no reply from Microsoft by publication, and did not quantify how many users were affected — [The Register, 2026-09-08](https://www.theregister.com/os-platforms/2026/09/08/bing-wallpaper-app-opens-harry-potters-chamber-of-ads/5295118)
- Windows Central framed this as the wallpaper becoming ad space; only the headline could be read — [Windows Central](https://www.windowscentral.com/microsoft/bing/microsoft-is-now-using-your-windows-11-wallpaper-as-ad-space)
- Reports describe the promotion on Windows 10 and 11 [Snippet] — [BetaNews](https://betanews.com/article/bing-wallpaper-harry-potter-ads-windows-11/). A "users uninstalling in droves" headline exists, but no uninstall count has been published, so treat it as unsupported — [Wilson's Media](https://www.wilsonsmedia.com/windows-11-desktop-becomes-a-full-page-harry-potter-ad-and-bing-wallpaper-users-rebel-by-uninstalling-the-app-in-droves/)

**October 2026: current state**
- Clicking the desktop opens Bing.com in the default browser, including when Chrome is default, and appears limited to once per 24 hours. The author could not find the 2025 toggle in the current version. No version number was given and no Microsoft response was reported — [Windows Latest, 2026-10-19](https://www.windowslatest.com/2026/10/19/microsoft-promised-fewer-windows-11-ads-but-its-wallpaper-app-acts-like-adware-opening-bing-when-you-click-your-desktop/)
- A pop-up still asks to set Bing as default search across browsers. Choosing "Enable now" attempted background browser changes; Chrome blocked the extension from being enabled, so Google stayed default — [Windows Latest, 2026-10-19](https://www.windowslatest.com/2026/10/19/microsoft-promised-fewer-windows-11-ads-but-its-wallpaper-app-acts-like-adware-opening-bing-when-you-click-your-desktop/)
- **Conflict:** a search summary of other coverage said a setting can disable the click behaviour, but that appears to describe the 2025 toggle; Windows Latest's 2026 test says it is no longer visible — [TechPowerUp](https://www.techpowerup.com/353908/microsofts-bing-wallpaper-app-hijacks-desktop-clicks-to-promote-bing-com) (not read in full)

**Reliability**
- Recurring complaints that images stop refreshing; replies point to dependence on its background service and to the app auto-updating [Snippet] — [Microsoft Q&A](https://learn.microsoft.com/en-us/answers/questions/5834019/troubleshooting-bing-wallpaper-that-doesnt-automat); [ElevenForum](https://www.elevenforum.com/t/why-doesnt-my-bing-wallpaper-automatically-update.41033/latest)

### Inferences
- Roughly 74% of the unpacked package is DLLs, mostly the bundled .NET runtime and UI stack, not wallpaper logic. Footprint here is a consequence of architecture plus promotional features (browser defaults, widgets, WebView2), not of the core job.
- `Local State` and `Secure Preferences` are Chromium profile file names. From background knowledge, `Local State` holds the key used to protect cookies and `Secure Preferences` holds extension state. Their presence is consistent with Rivera's account and with the browser-default feature, but does not prove cookie decryption in 1.1.459. The absence of plain `Cookies`/`MUID` strings does not rebut him either: strings can be encoded or delivered by remote config, and he examined a 2024 build.
- `SetWindowsHookEx` in the Widgets DLL is a plausible mechanism for detecting desktop clicks. This is speculation from a string count, not an established fact.
- `dc.services.visualstudio.com` is, from background knowledge, an Application Insights ingestion host, suggesting telemetry from the extension. Confirm with a network capture before repeating it.
- Rated 4.5 stars from only 781 US ratings, the Store score is not a useful signal of the 2026 backlash.

### Gaps
- **No measured RAM/CPU/process count for Bing Wallpaper was found.** A "15-20 MB" figure surfaced in a search summary, but could not be traced to a specific page, so it is excluded. Measuring needs an isolated install (Windows Sandbox or a VM).
- Whether 1.1.459 is what users currently run is unknown. The app auto-updates and is reportedly remotely configurable, so behaviours from September and October 2026 may be in later builds or config, not this package.
- The telemetry content, data destinations, and any 2026 re-test of the cookie claims were not found. No 2026 Microsoft statement was found.
- Reddit threads could not be read directly, so Reddit sentiment is second-hand via The Register.

## What does Windows Spotlight on the desktop offer natively in Windows 11, and what are its limits?

### Takeaway
Spotlight gives zero-install daily images and a next/like/dislike control, but it is a single Microsoft-curated feed: no documented category or source choice, no per-monitor assignment, a persistent desktop icon with no official hide setting, and Bing-linked behaviour. It removes the need for an app for undemanding users; it does not cover backreel's target features.

### Cited Findings
- Windows 11 Spotlight displays a new image on the lock screen and background every day, plus suggestions, fun facts, and tips in places including the lock screen, background, taskbar, and Get Started. The Windows 10 text mentions the lock screen only for the daily image — [Microsoft Learn, updated 2026-02-20](https://learn.microsoft.com/en-us/windows/configuration/windows-spotlight/)
- After KB5046633 (2024-10-22) the default Windows 11 wallpaper changes to Spotlight. After KB5048652 (2024-12-10) the same happens on Windows 10 — [Microsoft Learn](https://learn.microsoft.com/en-us/windows/configuration/windows-spotlight/). This is notable: the Windows 10 note conflicts with the page's own lock-screen-only description.
- The documented policies only turn parts on or off (`AllowSpotlightCollection` by CSP only, `AllowThirdPartySuggestionsInWindowsSpotlight`, `ConfigureWindowsSpotlightOnLockScreen`, and others). None select image topics — [Microsoft Learn](https://learn.microsoft.com/en-us/windows/configuration/windows-spotlight/)
- **Conflict:** the same doc says Spotlight is "available on Windows Enterprise and Education editions only" — [Microsoft Learn](https://learn.microsoft.com/en-us/windows/configuration/windows-spotlight/). Yet a Windows 11 Home user is discussing it in Settings in a 2026 thread — [Microsoft Q&A](https://learn.microsoft.com/en-au/answers/questions/5787280/spotlight-on-monitor-1-and-wallpaper-background-im). The licensing line likely concerns managed configuration, but the doc does not say so.
- Requires Windows 11 22H2 (build 22621) or later. A "Learn about this picture" icon sits at the top right of the primary desktop. Right-click offers "Switch to next picture", "I like this picture", and "Not a fan of this picture"; double-click opens a Bing page in Edge — [Digitash, 2026-10-14](https://digitash.com/microsoft/windows/enable-customise-windows-spotlight-desktop-windows-11/)
- One guide also says an activated licence is needed [Snippet] — [Pureinfotech](https://pureinfotech.com/enable-spotlight-desktop-windows-11/)
- Multi-monitor: an Independent Advisor (not Microsoft) states the setting applies to all screens, so Spotlight on one monitor with a custom picture on another is impossible (2026-02-25) — [Microsoft Q&A](https://learn.microsoft.com/en-au/answers/questions/5787280/spotlight-on-monitor-1-and-wallpaper-background-im). An October 2026 guide also says it cannot be set per monitor, but suggests a thumbnail workaround that is unclear [Snippet] — [Geek Rewind](https://geekrewind.com/how-to-use-different-backgrounds-on-each-display-or-desktop-on-windows-11/)
- The icon has no dedicated off switch while keeping Spotlight; removal needs a registry edit or ExplorerPatcher. Sources disagree on the value (0 vs 1) [Snippet] — [Windows Latest, 2024-12-25](https://www.windowslatest.com/2024/12/25/permanently-remove-learn-more-about-this-picture-icon-in-windows-11/); [gHacks, 2022](https://www.ghacks.net/2022/06/01/how-to-remove-windows-spotlights-learn-about-this-picture-icon-from-your-desktop-in-windows-11/); [Microsoft Q&A](https://learn.microsoft.com/en-us/answers/questions/5524099/how-can-i-remove-the-search-the-web-to-learn-more)
- Images and advertisements come from Bing via the Content Delivery Manager, downloaded every 1 to 3 days. Files have no extension and metadata is stripped. This Wikipedia description is lock-screen focused — [Wikipedia](https://en.wikipedia.org/wiki/Windows_Spotlight)
- Windows Latest recommends Spotlight as the escape from Bing Wallpaper — [Windows Latest, 2026-10-19](https://www.windowslatest.com/2026/10/19/microsoft-promised-fewer-windows-11-ads-but-its-wallpaper-app-acts-like-adware-opening-bing-when-you-click-your-desktop/). Other coverage cautions it draws on the same image service and has carried promotional content [Snippet] — [BetaNews](https://betanews.com/article/bing-wallpaper-harry-potter-ads-windows-11/)
- Lock screen: one secondary source says Windows supports only one lock screen image system-wide [Snippet] — [GeekChamp](https://geekchamp.com/?p=240282)

### Inferences
- Because Spotlight is the default wallpaper since late 2024, backreel competes with a free default, not just with Bing Wallpaper. Its pitch must be choice and per-monitor control, not "daily pictures".
- The like/dislike control is the only personalisation in Spotlight, and it is opaque. Explicit user-chosen categories are a clear contrast.

### Gaps
- No official Microsoft statement on Spotlight multi-monitor behaviour was found.
- No documentation of any category selection was found; this is absence of evidence, not a Microsoft statement that none exists. No 2026 Insider change was found.
- No figures were found for Spotlight's background CPU, RAM, or network use.
- Image resolution for desktop Spotlight was not verified from a primary source.

## How do the alternatives compare (stack, sources, categories, multi-monitor, price, footprint, maintenance)?

### Takeaway
There is a sharp split. Tiny native tools are single-source (mostly Bing-only), while multi-source apps ship at 31 MB to 290 MB or more. No app found publishes measured RAM. John's Background Switcher and DMT Wallpaper Changer are the most capable classic utilities; Wall/Art/Shift is the closest conceptual competitor but is a 102 MB Python app; Spice is the newest serious multi-source app at 98 MB.

### Inferences
- Installer size tracks runtime choice closely: native Rust and small C# builds are 2-5 MB, Tauri about 5-7 MB, bundled .NET 50-70 MB, Python about 100 MB, Go + Fyne about 100 MB, Electron 65-220 MB. Feature count explains far less. Installer size is only a proxy, and it does not predict idle RAM.
- Tauri's small installer hides a WebView2 runtime cost at run time, so it is not automatically "minimal". This is background knowledge and has not been measured here.
- A wallpaper job is needed once a day. Resident design is confirmed only for Bing Wallpaper (startup task in its manifest) and stated for Wall/Art/Shift ("runs in the tray"); process models of the other apps were not checked. A run-and-exit design would have near-zero idle cost by construction, and whether any existing app already does this is unknown.

## Which open-source projects are good references for code and design?

### Takeaway
Variety is the best reference for multi-source architecture, and its issue tracker shows what goes wrong. For Windows-specific wallpaper code the most useful are WallP (multi-monitor CLI), WinDynamicDesktop (mature tray app), and Spice (per-display controllers). For size targets use wwb BingWallpaper and SpotlightSaver.

### Inferences
- Copy Variety's shape (one small module per source, configured instances) but not its multi-monitor debt. A retrofit has been open for eight years, so per-monitor state should be in the data model from the start.
- Embedded third-party API keys are a long-term liability, as Variety's expired key shows, and requiring users to supply one (Splashy, DMT for Flickr) is onboarding friction. Keyless sources or an explicit key strategy deserve an early decision.
- Licence constraints matter for code reuse: Variety and Lively are GPL, dwall AGPL, Spice noncommercial, and wwb has no licence. MIT candidates for direct borrowing are wpc, WallP, SpotlightSaver, philhansen/WallpaperChanger, and daily-desktop.
- Small unsigned Windows binaries that fetch from the internet and change system state are prone to antivirus false positives, which makes code signing a planning item, not a polish item.

### Inferences

**Where the real gap is.** Across everything surveyed, no single app was found combining all of the following:

| Requirement | Who has it | Who misses it |
|---|---|---|
| Installer under about 10 MB | wwb, BingWallpaperDesktop, Bing Wallpaper Now, Splashy, SpotlightSaver | All multi-source apps except Splashy, which is one provider |
| Several unrelated sources | JBS, DMT, Wall/Art/Shift, Spice | Tiny clones; Bing Wallpaper; Spotlight |
| User-selectable categories across sources | Wall/Art/Shift; partly Spice and JBS via queries | DMT; tiny clones; Spotlight |
| Real per-monitor control | DMT, Spice, Wall/Art/Shift (Pro) | Spotlight; Variety on Linux; most clones |
| No ads, browser changes, or account | Most independents | Bing Wallpaper |
| Published, reproducible RAM/CPU numbers | **Nobody found** | Everyone |

- The gap is the *combination*, not any single feature. Each feature already exists somewhere. Claiming "first multi-source wallpaper app" would be false.
- "Minimal footprint" is the least-contested position: many apps claim "lightweight", and none found prove it. Publishing a reproducible idle-memory figure would be a real differentiator at low cost.
- "No resident process" may be the strongest specific claim, if it survives validation against JBS, DMT, and Dynamic Theme, none of whose process models were verified here.
- Timing favours this: the 2026 ad and click stories create an audience actively seeking a replacement. Press recommendations currently offer only Spotlight, Windows slideshow, or vaguely "a third-party app", which suggests no recognised default alternative. This rests on a few articles, and it is an opening rather than proven demand.
- The strongest competitive threats are JBS (broad sources, free, long-lived), Wall/Art/Shift (same concept, cheap Pro tier, heavier runtime), and Spotlight (free and already the default). Bing Wallpaper itself is more a source of disaffected users than a competitor.
- Trust features are product features here: no telemetry by default, no browser contact, no desktop click handling. Given the history, these belong in the pitch. An option to exclude AI-generated images is a cheap differentiator.
- Likely v1-level expectations from users switching: history and back/next, favourites, pause, storage cap, attribution caption, and a visible failure state when refresh fails.

### Gaps
- **Reddit was not read directly**: searches returned no Reddit threads and only second-hand descriptions. A manual pass over r/Windows11, r/windows, and r/software is advisable.
- Microsoft Store review text was not retrieved; only aggregate ratings and The Register's summary were available.
- No quantitative market data was found: no install counts for Bing Wallpaper or alternatives, and no uninstall data after September 2026.
- Issue reaction counts are small, and Variety's are Linux users; they show relative priorities, not market size.
- Feature demand for categories in particular is weakly evidenced: no direct user request for cross-source categories was found, though the concept is implied by Wall/Art/Shift, Splashy, and Bing's own themes. Validate before treating it as a headline feature.
- The legality and terms of using Bing or Spotlight image feeds in a third-party app were out of scope here and remain unverified.
